# 可以直接发给 Agent 的准备提示词

先打开本仓库作为 Agent 的工作目录。下面的提示词适用于能读取本地文件和运行命令的 ChatGPT Work、Codex、Claude Code 等外部工具。普通网页聊天若无本地访问能力，需由用户提供任务材料；不能声称已读本机文件。把方括号替换成自己的信息即可，其他参数由 Agent 查正式工具目录。

## A. 第一次安装与环境准备

```text
请帮我在当前电脑准备 MathProblemBank 的数学与英语工作环境。
先完整读 AGENTS.md、GETTING_STARTED.zh-CN.md、docs/MACOS_SETUP.zh-CN.md（仅 macOS）和 docs/ARCHITECTURE.zh-CN.md，运行 git status，保留已有改动。
系统是[Windows/macOS]，我希望数据保存在[默认位置/指定目录]。
检查 Python 3.12、Tk、.venv 和公开依赖，缺失时在项目本地准备；不要更改无关系统、代理、安全或其他工具配置。
先验证基础命令与空数据的数学、英语入口；再检查 XeLaTeX/latexmk。OCR、MinerU、Groq、媒体、词典和朗读分开列明用途与实际状态，不将可选项误报为已可用。
在隔离数据目录走通最小测试，不使用我的正式数据库做实验，不下载或导入未授权教材。密钥由我通过本地设置填写，不要求我发到聊天，不回显凭据。
完成后给我启动方式、实际数据位置、验证结果和仍缺的组件；不要只列安装计划。
```

## B. 新数学学习项目与教材准备

```text
请把[课程/教材主题]准备成可持续使用的数学学习项目。目标是[学习问题集/网课讲义/教材习题集/译本]，我的基础是[先修知识]，材料是[本地PDF/合法来源链接/已录课程]。
先完整读 AGENTS.md、.agents/skills/mathproblembank-workflow/SKILL.md、docs/CHATGPT_WORK_GUIDE.zh-CN.md，再运行 workflow start，核对已有学科、项目、教材、课程和 WORK_CONTEXT.json，复用已有成果。
自行通过正式工具目录查 schema、创建缺少的目标、登记并绑定教材、检查检索/OCR健康；网课另核对 MinerU 正文/公式/图像和教材目录，不把索引当作完成解析。
准备过程由你衔接，不让我手写 JSON、重复下载或重录已有材料。需要联网发送材料或付费解析时说明服务和范围；未获授权则保留待办，继续能离线完成的部分。
实际读对应原页和相关参考书，保留教材原图与真实出处。先完成材料准备和交接，再按任务范围写作；不要仅生成一个空项目便称完成。
```

## C. 写作或继续一集数学讲义

```text
请完成[课程与集数/小节]的正式讲义。先读学习流程并运行 workflow start，核对交接与正式状态。
新录集按 intake-task 读全部转写和截图缩略图，自行写 INTAKE.json 并 intake-apply；旧锁定材料复用。每10分钟最多一个正式小节，默认整集处理。
逐主题实际读主教材、参考书和作者笔记，完成 SOURCES.json 的 reading 与 teaching_plan 并通过本地检查后再写正文。讲清对象、映射、条件、构造及逆构造，展开关键计算和证明；定义保持简洁，解释放在注记和例子。保留本节应有的结论、例子、来源贡献和原图，不扩展到后续章节证明，不自动加习题。
由你自己逐小节对照教材、自检并补全，再运行 episode-check/collect。含英文正文时主动逐段筛选难句，在最终PDF上定位，按 reading task/check/collect 写好详细中文讲解并保存到阅读器，核对显示。
不调用独立数学审计模型。正式PDF、目录、图和阅读辅助检查完后保存项目交接，如实报告完成项和未完成项。
```

## D. 英语材料、笔记与试卷准备

```text
请为我的英语学习准备[材料/教材笔记/题目笔记/试卷导入]，材料位置是[位置]，目标是[目标]。
先读 AGENTS.md、完整学习流程和提示词目录，运行 workflow start，查已有材料与任务，使用当前工具返回的数据目录，不读取维护者的外部教材目录。
笔记使用 notes prepare/collect 的正式任务；试卷先 exam prepare，逐页核对原卷写 EXAM.json，答案无可靠来源就留空，再 exam check。
试卷正式导入前把题数、题型、新增/更新、答案来源和留空项给我预览；得到同意再用正式入口导入。不要直接写 SQL、猜答案或把少数样题冒充整份试卷。
对我的作答批改时用 grading prepare，并在指定 FEEDBACK.md 写完整反馈；阅读器讲解用 reading task/check/collect 保存。遵守 TASK 的格式和唯一规范，保留原文、来源及我的想法。
完成后重新读取正式目标，核对笔记PDF或阅读器显示，列明实际入库和待办。
```

在隔离数据根复现，再做最小修改；不重写窗口、不直接修正式数据库、不新增模型接口。可重复的业务能力维护 OperationSpec、schema、执行器、权限与证据的一致性。
运行适当的语法、聚焦测试、注册表完整性与执行器真实调用测试；涉及PDF或UI时实际检查。最后报告改动文件、验证结果和未验证边界，不自行发布或删库。
```

本次完成后通过 save_workflow_context 保存覆盖、产物、决定和下一步；不能用交接里的文字代替外部调用或删除授权。
```
