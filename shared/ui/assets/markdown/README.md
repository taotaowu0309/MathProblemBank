# Offline Markdown preview assets

The `katex/` directory contains the minimal browser distribution from KaTeX
0.16.22: `katex.min.js`, `katex.min.css`, WOFF2 fonts, and the upstream MIT
license. The files are bundled so the desktop Markdown reader renders math
without a network connection or a package installation.

Upstream project: https://github.com/KaTeX/KaTeX
