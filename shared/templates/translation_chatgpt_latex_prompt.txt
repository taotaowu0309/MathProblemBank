你正在执行 MathProblemBank 数学译本工作流的第三层：把一个明确的节或小节翻译成中文 LaTeX 正文。

一、范围与事实源

1. `target.json` 唯一决定本次允许输出的范围和最小单位。目标为 section 时，完整输出该节及其中全部小节；目标为 subsection 时，只输出该小节。不得顺带翻译相邻内容。
2. `source/chapter.pdf` 是可见数学内容、结构、编号、公式和图表的最高事实源。必须按照 `target.json` 的 `source_pages.chapter_pdf_page_start/page_end` 查看目标页面；相邻工作单元可以共享同一物理页，不得只根据 Markdown 猜测。
3. `markdown/section_corrected.md` 是第二层按原书语言校正后的主要文字底稿；它不是中文译文。如果该文件不存在，才以 `markdown/section_mineru.md` 为底稿。
4. `markdown/section_mineru.md` 只是 MinerU 原始识别证据。两份 Markdown 冲突时，以原书 PDF 为准；不得把 Agent report 当作正文。

二、翻译职责

0. 本层属于正式数学译文，不得使用轻量、mini、fast 或降级模型。必须使用 `gpt-5.6-sol / medium` 或项目明确指定的更高质量配置；如果当前会话无法确认模型，不要生成译文。材料包只能规定该合同，不能替会话选择模型。
1. 中文翻译只在本层发生。把目标范围的原书语言忠实翻译为简体中文，同时保留定义、假设、量词、否定、结论、证明依赖、公式、符号、上下标、边界、编号、脚注、引用和段落顺序。
1.1 每个原文自然段必须对应恰好一个中文自然段；不得合并、拆分、调序、概述或扩写。翻译后必须逐页对照 `source/chapter.pdf`，确认原书页面上的每一段都在译文中恰好出现一次。
2. 不得添加原书没有的解释、证明步骤、例子或评价；不得删去看似重复但原书存在的内容。
3. 原书疑似有错时保留原文含义，不得静默修正。确实无法可靠判断的局部，用简短 LaTeX 注释 `% UNCERTAIN: ...` 标记，不得猜测。
4. 数学家姓名、以人名命名的术语和通行专名保留规范英文拼写。中文正文使用英文标点，句末使用 ASCII `.`。

三、LaTeX 输出合同

1. 必须遵守本文件末尾直接附带的“正式译本导言区环境（强制）”；同一合同也单独保存为 `LATEX_CONTRACT.md` 供核对。它与题库管理中心正式译本 PDF 的共用导言区一致，只规定可用的正文环境和命令；不得发明模板中不存在的环境。
2. 只输出可以直接导入当前项目的目标正文 LaTeX；不要输出 Markdown 围栏、说明文字、`\documentclass`、导言区、`\begin{document}`、`\end{document}`、封面或整本目录。
3. 沿用原书的 section/subsection 层级和定理类环境。必要时可以调整环境编号以符合原书，但不得改变数学结构。
4. 第二层 Agent 已把当前目标的全部英文 ASCII 标签和每一次引用写入 `AGENT_LABELS.json`；它是强制执行清单，不是建议。`definitions` 中的定理、定义、命题、引理、推论、注记、公式、图和表标签必须逐字放入对应环境；`references` 中每条记录必须按 `occurrences` 次数落实为 `\ref`、`\eqref`、`\pageref` 或 `\hyperref`。不得把清单内的章、节、小节、定理或公式编号继续写成不可点击的纯文字。对尚未导入的未来目标，用 `\hyperref[label]{原文可读编号文字}` 保留正常显示，目标导入并全书重编译后会自动成为可点击链接。
5. `REFERENCE_INDEX.json` 是全书唯一标签命名空间，包括尚未翻译的未来单元。只能逐字使用 `AGENT_LABELS.json` 和该索引中已有的英文标签，不得硬编码编号或自造标签。章、节、小节锚点由题库管理中心落盘，正文不得重复定义。
6. 公式必须保持数学等价且忠于原书。不要把公式改写成 Unicode 近似字符，不要随意更换作者记号。
7. 有序列表使用 `enumerate`。不要手工键入列表编号。
8. 原书引用他人文字时，必须使用合同中的 `quotationblock` 环境，并用 `\quoteattribution{作者与出处}` 单列出处。共用模板会让引文与脚注使用同一个、只比普通正文略小的次级字号并左右收窄；不得在正文中手工设置字号，也不得把引文和出处混排成普通正文。

四、图片与表格

1. `images/` 中的 PNG 是程序从原书生成的正式截图资产。必须使用压缩包内的实际文件名通过 `\includegraphics` 引用；不要重画，不要生成 TikZ 或 tikz-cd 替代图。
2. 保留原书图题、表题、编号和正文引用关系。`images/manifest.json` 用于核对图片来源页、裁切和文件名，不是正文。
3. 如果目标范围内应有图片但压缩包缺失，保留明确的 `% MISSING_FIGURE: ...` 注释，不得虚构图片代码或内容。

五、提交前自检

逐项确认：目标范围没有越界；数学内容无遗漏；原书结构和编号得到保留；所有公式定界正确；正文中不存在可跳转对象的硬编码编号；所有引用标签均来自 `REFERENCE_INDEX.json`；所有图片路径确实存在；输出只有 LaTeX 正文。完成后直接给出最终 LaTeX，不附加解释。
