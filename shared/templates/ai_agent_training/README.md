# 题库管理中心 AI 项目适配训练包

这套文件不修改第三方模型的权重。它通过每轮动态注入的项目规则、工具工作流、少量示范样例，以及用户明确导入后才存在的学习画像，让不同 OpenAI 兼容、Responses、Claude 与 Gemini 模型遵守同一套行为。

设计原则：

- 本地题目、当前项目 PDF 的 TeX 来源和绑定教材优先于模型常识。
- 只注入当前任务需要的训练模块与至多两个示例，避免无意义消耗 API 输入额度。
- 默认不创建或注入学习画像；只有用户显式导入的本地 UTF-8 文本才会生效，且可以随时替换或清空。
- 工具能力从程序中的真实工具定义动态生成，避免训练文档与代码功能漂移。
- 标准题、教材映射、项目 TeX/文本和历史对话使用统一本地索引定位；精确内容仍回到原始来源读取。
- 用户标记“有帮助”的回答可成为相关问题的本地风格示例；所有记忆都可以在“学习记忆”窗口查看、编辑或删除。
- “测试、预览、看看效果”默认只读；只有明确要求写入、插入或修改项目时才允许落盘。
- TeX 写入必须经过备份、增量 PDF 生成和正式 PDF 替换；任何一步失败都回滚。
- 统一索引覆盖标准题、项目 TeX/笔记、绑定教材 PDF 页块、项目 PDF、MathWorkspace 和历史对话；检索结果保留文件路径或 PDF 页码。
- 每轮建立可持久化执行计划。工具失败进入重规划状态，替代步骤没有完成时不得仅凭文字回答宣称任务完成。
- 数学质量样例成对保存优选回答与反例回答，并按固定 rubric 验收；不得机械复制旧题的数学内容。
- 数学工作区支持受控跨文件事务，但不开放程序源码、数据库、系统目录或任意终端。

文件说明：

- `behavior_policy.md`：所有任务都适用的行为约束。
- `math_style_guide.md`：数学解释的深度、结构与语言要求。
- `tool_workflows.md`：项目检索、绘图、TeX 写入和 PDF 更新流程。
- `few_shot_examples.json`：按用户消息关键词选择的正反示例。
- `training_manifest.json`：决定每类消息加载哪些模块以及最多注入几个示例；以后可直接调整，无需修改程序。
- `acceptance_cases.json`：换模型或修改规则后的验收场景。它本身不会发出 API 请求，也不会消耗余额。
- `math_quality_pairs.json`：人工确认的成对数学偏好样例。
- `math_quality_rubric.json`：数学正确性、资料忠实度、讲解深度、学习者适配和工具真实性的固定评分标准。
- `system_acceptance_suite.json`：定义题、证明解释、搜题、绘图、项目操作和跨文件任务的系统验收题型。

使用方式：程序每次发送请求前都会重新读取这些文件，因此修改训练内容后下一条消息即可生效；只有修改 Python 程序本身才需要重启题库管理中心。建议先修改规则或示例，再从 `acceptance_cases.json` 选一个最相关场景做真实 API 测试，不要批量消耗余额。
