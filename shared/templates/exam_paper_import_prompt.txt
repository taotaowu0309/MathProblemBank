【工作步骤——按顺序做，每一步都要真的调用工具，不要凭印象】
1. 调用 get_english_exam_import_format，读懂试卷 JSON 的格式、字段、标记语法和题型分类。
2. 用 read_exam_pdf_text 读出整份 PDF 的文字（长卷按 next_page 分段读完，不要漏页）。如果 text_layer 为 false（扫描件），先告诉我，不要猜文字。
3. 按格式整理整套试卷：
   - exam 写考试名称（如“考研英语一”“考研英语二”），year 写四位年份，paper_code 如 KY-E1-2025；卡片上会显示“年份 + 英一/英二”，必须写清楚。
   - 每篇文章一个 group，完形的空写成 [[题号]]，翻译划线句用 <u>…</u>；题号与原卷完全一致。
   - 文章、题干、选项逐字照抄 PDF：不改写、不纠错、不补全；PDF 自动折行要接回整句，段落之间空一行。
   - source_pdf 填上面这份 PDF 的路径，source_page 填题目所在页。
4. 答案（最重要，宁缺勿错）：
   - 试卷 PDF 自带答案，或我在对话里给了答案/答案来源时，以它为准。
   - 否则只用可靠的公开答案，至少两个独立来源一致才采用；不一致或查不到的题，answer 留空并告诉我是哪几题。
   - 在 answer_source 写清楚答案来自哪里；非官方答案要写“非官方参考答案”。
   - 解析写简短中文，说明依据在原文哪一句；explanation_source 写 ai。翻译、写作题的 reference 是你写的参考译文/范文，同样标 ai。
5. 核对：调用 check_english_exam_paper（paper 用整理好的对象，pdf_path 用上面的路径）。
   - 逐条处理它报告的问题：文字与 PDF 对不上的地方回到 PDF 改正，答案不在选项里、题号缺漏、完形空格与题目对不上等都要改。
   - 重复“修改 → 核对”，直到没有问题；确实是 PDF 本身的问题（如原卷印刷错误）就保留原样并告诉我。
6. 调用 preview_english_exam_paper，把预览结果（题数、题型分布、新增/更新、提醒）和答案来源、留空的题告诉我。
7. 等我明确同意后再写入：
   - 在 Windows 上：调用 import_english_exam_paper，写入后报告回读结果。
   - 在 Mac 上（Mac 的数据库会被 Windows 同步覆盖）：调用 send_exam_paper_to_inbox 放进导入收件箱，Windows 的控制中心启动时会自动导入。

【不要做的事】
- 不要跳过 check_english_exam_paper，不要在核对有问题时导入。
- 不要编造答案、不要为了“通过核对”改动原卷文字。
- 不要一次只导入一部分；整套试卷作为一个 paper 导入（题目以后可以按题号重新导入更新）。
